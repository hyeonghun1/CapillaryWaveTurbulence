# CapillaryWaveTurbulence

This repository contains the codebase for the work "Stochastic reduced-order modeling of capillary wave turbulence via
Operator Inference using experimental measurements." 

The code is based on and extends the methodology introduced in:

[1] M. A. Freitag, J. M. Nicolaus, M. Redmann
